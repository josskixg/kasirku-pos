# KasirKu — Offline-First UMKM POS & Bluetooth 58mm Thermal Printer

Aplikasi Point of Sale (POS) ultra-ringan berbasis Web PWA & Android untuk UMKM kuliner/retail. Berjalan **100% offline tanpa biaya langganan bulanan**, dilengkapi encoder **ESC/POS 58mm via Web Bluetooth API** dan kalkulator **Harga Pokok Penjualan (HPP) + Laba Bersih otomatis**.

## Fitur Utama
- **Zero-Dependency & Hemat RAM (<5MB)**: Murni HTML5/CSS3/Vanilla JS, tanpa bundler berat.
- **Direct Thermal Print 58mm**: Menghasilkan byte stream ESC/POS langsung ke printer Bluetooth 58mm murah.
- **Rekap HPP & Laba Bersih**: Hitung margin keuntungan per transaksi secara instan dan unduh laporan CSV/Excel.
